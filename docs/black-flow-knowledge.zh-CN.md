# 黑流树海规划知识库 v0.1

更新时间：2026-07-26

这份资料用于把视觉识别结果转成可计算的路线规划状态。机器可读版本位于
`data/knowledge/black-flow-rules.v0.1.json`。由于主题刚上线，PRTS 和 BWIKI
仍在快速编辑，所有规则都保留来源与可信度；社区攻略中的结局步骤被标为中等
可信，算法推导的几何范围被标为待实机验证。

## 当前覆盖

- 20 类地图节点及其资源作用；
- 30 个零件：12 个自然物、12 个加工品、6 个概念体；
- 徒步、密道与12种加工品对应的移动模型；
- 三个结局的关键前置、Boss 和可选削弱路线；
- 31 个普通/紧急作战关卡、6 个险路恶敌和10个追猎关卡的层级归属；
- 流窜居民、实托邦与未知视野三类动态地图状态。

`vision_bridge` 负责把视觉模块识别出的中文节点名和粗分类映射到上述规则 ID。
文字识别明确时按名称映射；只有“未知的凶戾/诡秘”时保留候选集合，规划器不得
假装已经知道真实事件。

## 对路线规划最重要的规则

1. 徒步每经过一个格点消耗1行动力，且不能跨过未完成节点。
2. 加工品可以跨过未完成节点；没有写明“无需行动力”的加工品暂按每次1行动力
   建模，但这一点仍需逐件实机复核。
3. 险路尽头把剩余行动力转成希望；险路小径把剩余行动力带到下一层。两个出口
   的最优选择取决于当前希望需求、招募券留存和后续层路线价值。
4. 羽瞰点是可重复行动力来源；再次前往仍可获得1行动力，因此规划器需要允许
   重访节点，而不是只做简单路径。
5. 零件箱满会阻止移动，自然物的出售时机和加工品使用次数都属于路径状态。
6. 流窜居民每次移动后也移动，会改变节点类型并阻断徒步路线，因此这是动态
   图规划，不是一次性的最短路问题。
7. 第三结局的怦然信标会提高敌方生命并大幅降低我方生命；路线价值必须同时
   考虑三个可选削弱标记，而不能只追求到达第六层。

## 仍需实机采集

- “周围12格”是否严格等价于曼哈顿距离不超过2；
- 所有普通加工品是否固定消耗1行动力；
- 节点、出口、事件、商店商品和零件掉落的概率；
- 各作战关卡在不同阵容、难度、藏品状态下的风险评分；
- 实托邦范围和流窜居民位置的实时 UI 识别。
