# 路线试算器 V0

## 目标

该版本用于在已经识别出的无向图上进行受控路线试算，不负责自动推荐最优路线，
也不会操作游戏客户端。

用户依次选择目标节点，并为每一步指定：

- 徒步跋涉；
- 当前零件箱中的某个加工品。

曲折密道不是可选移动方式。使用徒步或加工品抵达密道入口后，程序立即将当前位置
强制更新到配对密道的另一端，传送本身不额外消耗行动力。

## 三本独立账

### 确定性资源

记录行动力消耗、羽瞰点获得的行动力，以及加工品明确写明的希望、源石锭或
行动力变化。

### 六类节点收益

按希望、源石锭、指挥经验、收藏品、招募券、零件分别统计。每一项保留
“确定值、可选区间、条件收益、仍待揭示”四种口径：

- 得偿所愿固定计 1 件收藏品；
- 狭路相逢胜利后的 2 张招募券记为条件收益，零件/收藏品记为互斥选择；
- 作战的指挥经验与源石锭标记为随区域/关卡变化，不套用旧肉鸽数值；
- 不期而遇、命运所指等必须识别具体事件后才能从“可能”转为数值；
- 行商购买和失与得置换标记为交易，不当作免费收入；
- 险路尽头的剩余行动力按 1:1 转为希望，另计 1 件加工品。

页面中的“各类节点收益口径”可以逐类查看上述规则。数据来自
`data/knowledge/node-rewards.v0.1.json`，便于后续补录最新实测表格。

### 零件估值

用户录入每件零件在当前游戏画面上的估值。加工品次数耗尽时，该零件从路线末端
估值中移除。已收录的动态估值规则单独更新：

- 血蕈：每完成一场作战，估值增加 2；
- 恋家果：每次移动后估值减少 2；
- 浪花：每次移动的随机变化使用区间累计。

零件估值不会与节点随机奖励混成同一个“总分”。

## 节点结算

- 林间空地：仅通行，不产生奖励。
- 普通、紧急和领袖作战：首次完成时记录对应战斗奖励和零件掉落机会。
- 羽瞰点：每次抵达均增加 1 行动力。
- 曲折密道：两端自动配对；抵达入口所需行动力照常计算，随后强制传送到另一端，
  传送为 0。
- “居民”据点：记录一次居民战斗、战后零件机会和驱逐本层居民。
- 流窜“居民”占领：记录一次居民战斗，完成后该位置视作林间空地。
- 普通一次性事件：只在首次完成时结算，随后按普通可通行位置处理。

如果半局截图无法区分一个林间空地过去是否为羽瞰点，可以在页面的“节点人工
修正”模式中明确标记；程序不会仅凭历史猜测。

## 边界

- 徒步只能逐段选择识别图中真实存在的相邻边。
- 加工品根据知识库中的行列距离、方向和目标类型校验。
- 小八界的目标具有随机性；页面允许选择一个终点进行情景试算，但会持续提示
  该终点并非可控结果。
- V0 不预测流窜居民下一步会走向哪个相邻节点，只结算用户明确标记的居民战斗。
- 出口跨层、完整事件选项、具体作战数值表将在后续版本处理。
