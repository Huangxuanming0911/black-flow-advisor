# 战斗奖励 UI 样本

本目录存放“沉沦者的黑流树海”战斗结算与战后奖励页面的真实截图，用于开发只读的奖励采集器。

## 数据边界

- 层数和战斗类别优先继承自进入战斗前的地图上下文。
- 结算页用于读取关卡名称、单场指挥经验、生命值和升级结果。
- 奖励页用于读取展示的源石锭、招募券、收藏品、零件等条目。
- “展示的奖励”和“最终收下的奖励”分开记录。
- 局内宝箱和宝物怪第一版不自动识别，战后由用户确认。
- 升级产生的希望上限、编队上限等奖励不计入战斗随机掉落。

## 战斗类别

“误入奇境内部”单独记录为位置环境，因为内部仍可能出现不同战斗类别。战斗类别使用以下互斥取值：

1. 狭路相逢
2. 普通作战
3. 紧急作战
4. 险路恶敌/Boss
5. 追猎
6. 流窜“居民”普通占领战
7. “居民”据点

因此一条样本可以同时表示“第三层进入的误入奇境内部 + 紧急作战”，不会丢失其中任何一层信息。

具体字段和样本人工标签见 `manifest.json`。
